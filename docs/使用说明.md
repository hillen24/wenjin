# 致知 · 使用说明

> 思想栖所 · 电脑版 + 手机版 · 数据在家，断网可用
> 版本：3.9.2（2026-10-30）｜开源协议：GPL-3.0

---

## ★ 3.9.2 自定义 TTS + 手机端优化（2026-10-30，最新，建议用这个）

**这一版补上了自定义语音引擎**。之前设置页里选了「自建服务」之后**一个输入框都没有**，模型和音色是写死在代码里的（`tts-1` / `alloy`），所以「自定义」这三个字其实是不成立的。现在：

- **三档服务商预设**：OpenAI / 硅基流动 / 自定义（OpenAI 兼容）。选一个就自动填好地址、模型和常用音色；
- **地址 / Key / 模型 / 音色 / 音频格式**全部可以改；
- **高级区**（点「端点 / 请求头 / 请求体」展开）：换端点路径、加自定义请求头（给 Azure 那种非 Bearer 认证）、加额外请求体参数（`gain` / `sample_rate` / `references`）；
- **「测试朗读」**按钮：一键自检。成功会告诉你音频多大、用了多久；失败会**把服务端说的真原因带出来**（例如 `HTTP 401 · Token is invalid.`），而不是干巴巴一句「连接失败」；
- **「拉取」音色**：服务商有音色接口的话能拉到下拉列表；拉不到会明说「请手动填写音色名」，不会假装成功。

**手机端**也修了几处：

- **安卓的原生 HTTP 会毁掉音频二进制** —— 系统层把音频 base64 送回来，旧代码当普通字符串处理，播出来是噪音。现在解回真正的音频数据，手机上的云端朗读终于能出声了（安卓 WebView 本身没有系统语音，所以这是手机端唯一能出声的路）；
- **触摸目标从 20~31px 提到 40px**：之前顶栏的按钮、段落末尾的朗读喇叭小得手指头点不准；
- **安卓硬件返回键**：会退回上一页；已经在最外层时再按一次提示「再按一次退出」；
- **「我的」页加了状态速览**：AI 模型通不通、朗读引擎有没有声音，一眼看到，点了直接去设置。

## ★ 3.9.0 第一个稳定使用版（2026-10-25）

成品：

- `致知-电脑版-3.9.2.exe`
- `致知-手机版-3.9.2.apk`

**3.9.0 干了四件事**

1. **文献研读与精读伴读打通**。你导入的文献，原文自动进书架——提取完方法论、概念，思路卡住时能直接回原文读那一段。页面上有「去读原文」直达；同一本书重复导入不重复占书架。
2. **内置三部完整公版书**。书库从 11 部节选扩到 14 部可通读：《道德经》全文八十一章、《庄子》内篇七篇全文 + 《秋水》《至乐》共 2.2 万字、皮科《论人的尊严》编译本。
3. **数据备份**。一键导出备份文件；电脑端每次文献入库前、退出前自动备份到本机磁盘（保留 10 份）；手机端自动备份留在本机存储（保留 3 份）；备份可列出来、可恢复、可删；恢复前强制确认，且恢复前的数据自动留一份。
4. **双端质感升级**。圆角整体放大、弹窗与浮层加毛玻璃、投影改柔影、导航选中态浮起。华丽但克制——颜色一个没动。

**3.8.0 干了什么：软件里有了第一个真 Agent——「文献研读」**

以前 AI 只陪聊（格物追问、论道对手、伴读三问）。这一版起，你可以把一整本哲学书倒进去，让它自己分段啃完，再把提炼出的方法论、概念、格物题、论题**填回软件的四个栏目**——不是你手抄，是预览勾选后一键入库。

1. **导入即分段，AI 逐段提取**。粘贴文本 / 选文件 / 拖进窗口都行；每段多大可调（1500 / 3000 / 5000 字）。超长文本不会把 AI 请求撑爆——每段是一次独立请求，独立重试、独立记账，一段失败不连坐别人。
2. **跑丢了能找回来**。分析途中随时暂停 / 继续 / 中止；中止或段失败后，「续跑未完成段」会把没跑成的段重新排队，已成功的不重跑；暂存区落在本机，刷新、误关、换视图都不丢，回来说不定还能接着入库。
3. **预览反选才入库**。提炼结果先堆在暂存区，逐条看过：可勾选、可单条移除；目标栏目里已存在的重复条目会自动取消勾选并标原因。确认后按「方法论 → 概念星系 → 日常格物 → 论道」的顺序落库。
4. **三个老栏目合并文献条目**。方法库里多出「文献」角标的方法（可删）；格物里多出文献题（直接走预置剧本，不耗 AI 额度）；论道里多出「文献论题」，选好哲学家一键开聊、问题预填。

**3.2 修过的（都是真机上用手指才踩得到的坑）**

| 问题 | 解法 |
|---|---|
| 星图 27 个名字糊成一团 | 手机上只留「已点亮 / 选中 / 悬停」的标签，其余只画点；HUD 里写明「点节点看名字」，点开底部面板照样看得到全名 |

**3.1 立起来的东西**

手机端是从零建起来的（3.0 时它还是空的）。为了不让两端再变成两份副本，
1200 行内联 `<script>` 里：

- 星图的力导向算法和 SVG 元素创建、指针事件、面板 HTML 拼在同一个函数里 → 算错了没法测
- AI 错误处理是 UI 函数里的一串正则 `aiHint()` → 想复用就得把 DOM 拖进来
- 全局 `settings` 对象被 30 多个函数直接读写 → 不知道谁会改它

**八个视图**统一上移到共享层，两个应用只保留各自的壳：电脑端是左侧竖排八项，
手机端是顶部状态栏 + 底部五格（方法论库 / 我的哲学 / 设置 收进「我的」聚合页）。

窄屏适配是第一轮的主要工程量，逐条都是 390px 真机上必然踩到的：

| 问题 | 解法 |
|---|---|
| 方法论库卡片被压扁、内容裁掉 | 显式 `grid-auto-rows: max-content` —— `overflow:hidden` 的 grid item 自动最小尺寸会被当成 0，十行挤在定高容器里就互相压 |
| 星图被挤成左边一条缝 | 右栏固定 296px 吃掉四分之三屏宽 → 窄屏改成底部滑出层，点节点弹出、点把手收起 |
| 星图节点点不中 | 视野按 680×540 宽屏比例铺，概念节点直径只剩 11px → 窄屏等比收窄视野，节点放大（3.2 又加了透明命中圈） |
| 手机上不能缩放星图 | 原来只监听滚轮 → 补双指缩放，两指中点作锚点 |
| 阅读器三栏没法读 | 200px 书架 + 正文 + 320px 伴读栏 → 一次一栏，顶部三段切换 |
| 格物条目压住下面的统计卡 | 主区溢出但不滚动 → 窄屏给主区加滚动（3.3 又整页重排了） |

## 一、这是什么

致知不是"哲学百科"，是一个**思维训练场**。八个栏目全部双向联通：

| 栏目 | 干什么 |
|------|--------|
| 概念星系 | 52 个概念节点的深空关系图谱：拖节点 / 滚轮或双指缩放 / 空白处抓手平移，点节点直跳原著 / 方法论 / 论道 / 格物 |
| 精读伴读 | 14 部内置原著（《道德经》《庄子》全文可通读），可载入自己的 .txt/.md 与文献研读导入的原文；划句三问、翻页阅读、Edge 神经网络音色朗读 |
| 文献研读 | 导入哲学文本，AI 分段提取，预览勾选后反哺方法论 / 概念星系 / 格物 / 论道（详见「七、文献研读」） |
| 方法论库 | 14 条可操作程序（SOP + 常见误用），直接用于格物；文献提炼出的方法带「文献」角标，可删 |
| 日常格物 | 晚间复盘四步闭环：选条目 → 烦扰 → 追问 → 二分 → 格物卡；文献题直接走预置剧本 |
| 论道 | AI 扮演十位哲学家（苏格拉底只问不答），聊完存入哲学书；文献论题一键开聊 |
| 我的哲学 | 格物/论道/伴读沉淀，AI 梳理成专属于你的书，可导出 .md |
| 设置 | 自己的 API、TTS 引擎、主题、数据备份 |

**怎么翻页（3.9.1 新增）**

精读伴读是能整本读下去的：正文区自己滚动，工具条左端有翻页组——

| 操作 | 效果 |
|---|---|
| 上一段 / 下一段 | 一次翻一段（跨度过大时自动改瞬时跳转，不卡） |
| 页码「第 n / N 段」 | 当前位置；正文顶端还有一条细进度条 |
| 继续读 | 跳到第一段还没读过的 |
| ↑ ↓ / PageUp / PageDown | 键盘翻段 |
| Home / End | 跳到开头 / 结尾 |
| 手机端底部常驻翻页条 | 上一段 · 第 n/N 段 · 已读百分比 · 下一段 |

点段落标记「已读」，书架上会显示「已读 n/N 段」，换本书回来点「继续读」就接得上。

## 二、电脑版（致知-电脑版-3.9.2.exe）

- **双击即用**，无需安装 Python / Node 等任何环境
- 首次启动需要 10 秒左右自解压（约 100MB 到系统临时目录），之后每次启动都是秒开
- 启动后在任务管理器里显示为 `致知-电脑版-3.9.2.exe` 是正常的（Electron 运行时的进程名，窗口标题是"致知 · 思想栖所"）
- **如果双击后毫无反应**：先查是不是系统里设过 `ELECTRON_RUN_AS_NODE` 环境变量（少数开发工具会设，会让 Electron 变成纯命令行模式）。命令行里执行 `echo %ELECTRON_RUN_AS_NODE%`，只要有输出，就到「系统属性 → 高级 → 环境变量」里把它删掉，再双击。
- 数据保存在本机应用数据目录，删除 exe 不影响
- 启动时会在本机 `47800` 端口起一个局域网同步服务（只监听内网，不出公网）。首次 Windows 防火墙询问请选「允许访问」；不想用也不影响任何本机功能

## 三、手机版（致知-手机版-3.9.2.apk）

- 把 apk 传到手机（数据线 / 微信文件传输 / 局域网共享都行），点击安装
- 系统提示"未知来源应用"时允许安装即可（这是自己签名的开发版，未上架应用商店）
- 手机端是专门的移动形态：底部五 Tab、点段落即问、星图单指平移 + 双指缩放、底部弹层

### 双端数据互通（3.3 起可用了）

**同一 Wi-Fi 下直接搬，不用导文件。** 电脑端是服务端，手机端是客户端，方向由你自己点：

1. 电脑端开着，进 **设置 → 局域网同步**，卡片上会直接显示本机地址（如 `http://192.168.1.5:47800`）
2. 手机端进 **设置 → 局域网同步**，把地址填进去 → 点「测试连接」，显示通路 + 两边数据条数
3. 想用电脑那份 → 点 **从电脑拉取**；想把手机上的记录送上去 → 点 **推送到电脑**

规则只有一条：**整包覆盖，不自动合并**。格物卡、论道记录、阅读进度这类数据两边各改一半之后没法判断谁对，所以不做双向合并——覆盖前会自动在本机留一份备份（保留最近三份），点错了还能回去。

- 端口固定 `47800`，被占用时电脑端会顺延到下一个可用端口并显示出来
- 手机填不了 IP 时，先确认两台设备连的是同一个路由器（不是一台连 Wi-Fi 一台连热点）
- Windows 弹"是否允许防火墙"时要允许（专用网络），否则手机连不进来

跨不了局域网时（比如在外地），仍可用 JSON 备份接力：设置 → 数据管理 → 导出全部数据 / 导入备份。

## ★ v2.0 打下的底子（2026-10-24）

### 1. 黑天 / 白天双主题

设置 → 外观 → 主题，两段切换，点击即时生效，**主题选择会被记住**，下次打开还是上次那套。

- **黑天（默认）**：深夜壳 `#0B0E14` 包住全应用，星图在深空里发光；唯独读书的纸卡留一盏暖灯，长时间读不刺眼
- **白天**：雾灰 `#F5F5F7` 底 + 纯白卡片 + hairline 细边，白天在教室/户外看也不反光

星图的节点、连线、标签、图例颜色**跟着主题一起换**，不是简单反色，是两套独立配色。

### 2. 质感：层次靠光影，不靠边框

- 双层柔和投影（近处一层薄描边 + 远处一层大范围弥散），卡片有真正的"浮起来"层次
- 弹层、状态栏、底部 Tab 用 vibrancy 半透明毛玻璃（backdrop blur + saturate）
- 字体走系统回退栈，分段控件做成一体式滑块
- 所有动效统一缓动 `cubic-bezier(.32,.72,0,1)`，不再有生硬的线性过渡

### 3. 全部小图标换成自绘矢量图

一个 emoji 都不剩了。29 个图标全部是内置 SVG sprite（1.8 描边、圆头圆角、跟随文字颜色），在任何系统、任何字号下都清晰，不会被 Windows 的彩色 emoji 字体搞成花脸。

### 4. API 配置重做（含自动拉取模型）

设置 → AI 服务：

1. 选服务商（Ollama / DeepSeek / 硅基流动 / 自定义）
2. 填 Base URL 和 API Key（Key 只存本机，不上传）
3. 点 **拉取** —— 自动请求服务端的模型列表：
   - OpenAI 兼容服务 → 读 `GET {BaseURL}/models`
   - Ollama → 读 `GET {BaseURL}/api/tags`
   - 拉回来填入下拉框，选一个即用；拉不到就手填，不会卡住
4. 点 **测试连接** —— 真发一次请求，显示成功才算接入（侧栏底部绿点=真 AI，黄点=预置脚本）
5. 接入后：伴读讲解、格物追问、论道六哲、哲学书梳理全部走真实模型；任何一环失败自动降级回预置剧本，功能不断

## ★ v2.1 修了什么（2026-10-24）

### 1. AI「配了 API 还是不通」——四个真根因全修了

这一版最重要的事。之前反馈的「填了 Key 却还是在跑预置脚本」，查下来不是一个 bug 而是四个：

| 问题 | 根因 | 现在的行为 |
|---|---|---|
| 关掉再打开就退回预置脚本 | 接入状态只是个内存变量，重启即丢 | 验证结果存本机（配置指纹），重开照样是接上的 |
| 改个字号 / 切个主题就掉线 | `saveSettings()` 无条件把接入标记清零 | 只看服务商 / Base URL / Key / 模型这四项，四项没变就一直有效 |
| 填完 Key 直接去用，还是预置脚本 | 必须手动点「测试连接」才生效 | **填完自动验证**；打开应用也会补验一次，不需要记得点什么 |
| 测试显示已接入，一用就掉回预置 | 上半部配的是「服务商」，实际调用读的是「主力」，两者不联动 | 两处强制同步；测试连接也改成真发一次对话，不再用 `/models` 糊弄 |

顺带修的：在设置里「拉取」选中的模型对主力不生效（之前只有"自定义"才会用你选的模型）；兜底服务没填 Key 时会把真实错误盖成"缺少 API Key"；遇到 401/403 会主动把绿点降级，不再假装已接入。

设置页顶部现在有一条状态带，直接告诉你：**已接入 · DeepSeek / deepseek-chat**、**待验证**、**连接失败（附原因和排查方向）**，或者**未配置**。侧栏底部那盏灯跟着它走。

## 五、朗读换成自然人声

有三个引擎可选，在 **设置 → 语音朗读** 里切换：

| 引擎 | 怎么用 | 适合谁 |
|---|---|---|
| **系统内置** | 什么都不用配 | 电脑端够用；**手机端基本没声**（安卓 WebView 不带系统语音） |
| **Edge 音色** | 要在电脑上跑一个桥接脚本 | 想要微软神经网络音色（晓晓/云希/陕西话晓妮…）且不想花钱 |
| **云端 API** | 填个 Key 就行 | **手机端唯一能出声的办法**；音质好，按量计费 |

### 5.1 Edge 音色（免费，音质最好）

1. 电脑安装依赖：`pip install edge-tts fastapi uvicorn`
2. 运行附带的 **edge-tts-bridge.py**：`python edge-tts-bridge.py`
3. 启动后会打印局域网地址（如 `http://192.168.1.5:8787/v1`）
4. 致知 设置 → 语音朗读 → 引擎选 **Edge 音色**，「桥接服务地址」填打印出来的
   （本机用 `http://127.0.0.1:8787/v1`，**手机填电脑的局域网 IP**，两台要在同一 Wi-Fi 下）
5. 音色下拉里选一个（推荐晓晓；老乡可以试试陕西话晓妮）

连不上时自动退回系统音，阅读不中断。

### 5.2 云端 API（3.9.2 新增，手机端就用这个）

设置 → 语音朗读 → 引擎选 **云端 API**：

1. **服务商**选一档：
   - **硅基流动**（推荐，国内直连快）：默认模型 `FunAudioLLM/CosyVoice2-0.5B`，音色有 8 个（anna/alex/benjamin/…）
   - **OpenAI**：`tts-1` 模型，音色 alloy/echo/fable/onyx/shimmer
   - **自定义（OpenAI 兼容）**：任何兼容 `POST /audio/speech` 的服务
2. **API Key** 填上（只存在这台设备上，不上传别处）
3. 点 **「测试朗读」** 自检。成功会显示音频大小和耗时；失败会把**服务端说的真原因**带出来（比如 `HTTP 401 · Token is invalid.`），照着改就行
4. 想挑别的音色可以点 **「拉取」**——服务商有音色接口才拉得到；拉不到会明说让你手填，不会假装成功

**高级区**（点「端点 / 请求头 / 请求体」展开）：

| 能改什么 | 什么时候用 |
|---|---|
| **端点路径** | 服务不是 `/audio/speech`（Azure 的 `/cognitiveservices/v1`、某家自研的 `/v1/tts`）。也能直接填完整 URL |
| **附加请求头** | 认证不是 Bearer 的时候（Azure 用 `api-key`）。填 JSON，如 `{"api-key": "xxx"}` |
| **附加请求参数** | 厂商的额外字段，如硅基流动的 `{"gain": -2, "sample_rate": 32000}` |

> 换了模型之后，音色 id 的模型前缀会**自动跟着变**（硅基流动的音色是「模型名:音色名」这种格式）。

### 5.3 手机端为什么必须用云端 API

安卓 WebView **不带系统语音合成**，「系统内置」引擎在手机上基本是哑的。
所以手机上要出声，只能走 **云端 API**（或让电脑跑 Edge 桥、手机填局域网 IP）。

## 七、文献研读（3.8.0 新增）

**一句话**：把整本哲学书倒进去，AI 分段啃完，提炼出的方法论 / 概念 / 格物题 / 论题填回软件的四个栏目。

**前提**：设置里接好 AI（和格物、论道用同一个）。没接入时页面会引导你去配置，不会白跑。

**三步走**：

1. **导入**。粘贴文本、选 `.txt/.md` 文件、或直接拖进窗口都可以。填个文献标题（如《理想国》），勾选这次要反哺哪些模块（默认全选），选段容量（默认 3000 字）。估算超过 80 段会被拦下提示拆小——那是为了保护 AI 请求不超限。**点「开始分析」的瞬间，原文就进了精读伴读的书架**（同一本书重复导入不重复占），所以提取完随时能回原文读那一段。
2. **分析**。点「开始分析」后每段独立请求：进度条 + 每段状态徽标（等待 / 分析中 / 完成 / 失败）+ 产物计数。途中随时**暂停 / 继续 / 中止**；中止或段失败后，**「续跑未完成段」**把没跑成的段重新排队，已成功的不重跑。分析产物先进**暂存区**（本机持久化）——刷新、误关窗口、中途去刷星图都不丢，回来还能「去预览入库」。
3. **入库**。预览页逐条过：可按模块筛选、单条移除、全选 / 全不选；目标库里已存在的重复条目会**自动取消勾选并标注原因**。确认后按「方法论 → 概念星系 → 日常格物 → 论道」顺序落库，出入库报告。

**入库之后去哪找**：

- 方法论库：卡片带玉色「文献」角标，类别行显示「文献 · 类目」；不想要了在方法详情里删（两步确认）
- 日常格物：选条目时多出文献题（玉色标识），直接走预置剧本，不耗 AI 额度；分拣页还能手动加自己的词
- 论道：右栏哲学家列表下方多出「文献论题」，点一下自动选中哲学家并预填问题
- 概念星系：文献概念作为自定义节点进「我的星区」，可删、可点亮、参与盲区统计

**刷新了怎么办**：暂存区有东西时，页面直接把你带回预览页——成果不会因为你手滑关掉窗口就没了。

**容灾说明**（一次性导入太多怎么办）：AI 窗口不会被撑爆——文本按段容量切开，每段是一次独立请求，独立重试、独立记账，一段失败只连累自己；单段超限会标失败原因，改小段容量或续跑即可。

## 九、数据备份（3.9.0 新增）

**先说清两件事的区别**：「局域网同步」是**换设备搬家**（电脑 ↔ 手机）；「数据备份」是**防误操作、防存储抽风**（本机留一份，随时能退回去）。

**手动**（设置 → 数据备份）：

- **导出备份文件**：电脑端弹系统另存为，手机端走浏览器下载，文件是一份 JSON，人可以自己存到网盘 / U 盘
- **从备份恢复**：选文件 → 页面先告诉你这份备份里有什么（几项数据、几张格物卡、几本书）→ 再点一次「确认恢复」才动手；恢复是整包覆盖，**恢复前的数据会自动留一份**
- **立即备份一次**：不等入库、不等退出，现在就存一份
- **自动备份列表**：时间、来历（文献入库前 / 退出前 / 手动备份）、大小一目了然，每份都能「恢复」或「删除」

**自动**（不用你惦记）：

| 时机 | 电脑端 | 手机端 |
|---|---|---|
| 文献入库前 | 存到本机磁盘 `%APPDATA%/致知/backups/`，保留最近 10 份 | 留在本机存储，保留最近 3 份 |
| 退出前 | 同上（文件名带「退出前」） | 不自动（手机随时可能被系统杀掉） |

**在哪儿找备份文件**：电脑端设置页「数据备份」那一栏会直接显示本机备份目录的完整路径，复制到文件管理器就能看见那些 `wj-backup-*.json`。
