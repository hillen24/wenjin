## ★ 3.3 工程版（2026-10-24，最新，建议用这个）

成品：

- `致知-手机版-3.7.0.apk`

**3.3 相比 3.2：两端数据终于通了 + 格物页重排**

这一版干的三件事：

1. **局域网双端互通**（之前一直缺的一块）。电脑端起一个本地 HTTP 服务，手机端连上来，一键整包搬迁。详见「三、手机版 → 双端数据互通」。
2. **手机端格物页重排**。之前是「上面列表滚、下面统计固定」的双滚动分屏，屏幕小的时候上下两块互相挤。现在改成单列一篇滚到底：统计压成一行四个数字，历史格物卡默认折叠，要看再展开。
3. 顺手把 `ELECTRON_RUN_AS_NODE` 那段死代码换成真能用的便携版重启路径。

**3.2 修过的（都是真机上用手指才踩得到的坑）**

| 问题 | 解法 |
|---|---|
| 星图 27 个名字糊成一团 | 手机上只留「已点亮 / 选中 / 悬停」的标签，其余只画点；HUD 里写明「点节点看名字」，点开底部面板照样看得到全名 |
| 最外侧节点的名字被切掉半个字 | 视野缩放原来只按节点云算，没算标签宽度 → 缩放系数从 0.62 收到 0.7，左右各留 15px |
| 圆点手指点不准 | 每个节点垫一个透明命中圈（视觉不变，命中区放大一圈） |
| 顶部提示条第二行被切半截 | `box-sizing: border-box` 下 `max-height` 把 padding 也算进去了 → 改成 `calc(3.2em + 17px)` |

**3.1 立起来的东西**

手机端是从零建起来的（3.0 时它还是空的）。为了不让两端再变成两份副本，
七个视图统一上移到共享层，两个应用只保留各自的壳：电脑端是左侧竖排七项，
手机端是顶部状态栏 + 底部五格（方法论库 / 我的哲学 / 设置 收进「我的」聚合页）。

窄屏适配是第一轮的主要工程量，逐条都是 390px 真机上必然踩到的：

| 问题 | 解法 |
|---|---|
| 方法论库卡片被压扁、内容裁掉 | 显式 `grid-auto-rows: max-content` —— `overflow:hidden` 的 grid item 自动最小尺寸会被当成 0，十行挤在定高容器里就互相压 |
| 星图被挤成左边一条缝 | 右栏固定 296px 吃掉四分之三屏宽 → 窄屏改成底部滑出层，点节点弹出、点把手收起 |
| 星图节点点不中 | 视野按 680×540 宽屏比例铺，概念节点直径只剩 11px → 窄屏等比收窄视野，节点放大（3.2 又加了透明命中圈） |
| 手机上不能缩放星图 | 原来只监听滚轮 → 补双指缩放，两指中点作锚点 |
| 阅读器三栏没法读 | 200px 书架 + 正文 + 320px 伴读栏 → 一次一栏，顶部三段切换 |
| 格物条目压住下面的统计卡 | 主区溢出但不滚动 → 窄屏给主区加滚动（3.3 又整页重排了） |

**和 v2.1 的差别**

| | v2.1 | 3.3 |
|---|---|---|
| 代码形态 | 两份单文件 HTML（13 万 + 12 万字符） | Vue 3 + TypeScript monorepo |
| 两端逻辑 | 两份副本，92 个同名函数里 62 个已漂移 | 共享一层，只有一套 |
| 自动化测试 | 19 条（靠注入 HTML 在浏览器里跑） | **146 条**（Node 里跑，约 2 秒） |
| 手机端 | 独立一套手写实现 | 与电脑端同一份视图，仅外壳不同 |
| 两端数据 | 各存各的 | **局域网一键互通** |
| 数据键 | 存 `wj_*` 键 | **沿用同一批键**，升级后设置/藏书/进度/格物卡全在 |

## 一、这是什么

致知不是"哲学百科"，是一个**思维训练场**。七个栏目全部双向联通：

| 栏目 | 干什么 |
|------|--------|
| 概念星系 | 27 个概念节点的深空关系图谱：拖节点 / 滚轮或双指缩放 / 空白处抓手平移，点节点直跳原著 / 方法论 / 论道 / 格物 |
| 精读伴读 | 读原著（可载入自己的 .txt/.md），划句三问，Edge 神经网络音色朗读 |
| 方法论库 | 10 条可操作程序（SOP + 常见误用），直接用于格物 |
| 日常格物 | 晚间复盘四步闭环：选条目 → 烦扰 → 追问 → 二分 → 格物卡 |
| 论道 | AI 扮演六位哲学家（苏格拉底只问不答），聊完存入哲学书 |
| 我的哲学 | 格物/论道/伴读沉淀，AI 梳理成专属于你的书，可导出 .md |
| 设置 | 自己的 API、TTS 引擎、主题、数据备份 |

## 二、电脑版（致知-电脑版-3.7.0.exe）

- **双击即用**，无需安装 Python / Node 等任何环境
- 首次启动需要 10 秒左右自解压（约 100MB 到系统临时目录），之后每次启动都是秒开
- 启动后在任务管理器里显示为 `致知-电脑版-3.7.0.exe` 是正常的（Electron 运行时的进程名，窗口标题是"致知 · 思想栖所"）
- **如果双击后毫无反应**：先查是不是系统里设过 `ELECTRON_RUN_AS_NODE` 环境变量（少数开发工具会设，会让 Electron 变成纯命令行模式）。命令行里执行 `echo %ELECTRON_RUN_AS_NODE%`，只要有输出，就到「系统属性 → 高级 → 环境变量」里把它删掉，再双击。
- 数据保存在本机应用数据目录，删除 exe 不影响
- 启动时会在本机 `47800` 端口起一个局域网同步服务（只监听内网，不出公网）。首次 Windows 防火墙询问请选「允许访问」；不想用也不影响任何本机功能

## 三、手机版（致知-手机版-3.7.0.apk）

- 把 apk 传到手机（数据线 / 微信文件传输 / 局域网共享都行），点击安装
- 系统提示"未知来源应用"时允许安装即可（这是自己签名的开发版，未上架应用商店）
- 手机端是专门的移动形态：底部五 Tab、点段落即问、星图单指平移 + 双指缩放、底部弹层

### 双端数据互通（3.3 起可用了）

**同一 Wi-Fi 下直接搬，不用导文件。** 电脑端是服务端，手机端是客户端，方向由你自己点：

1. 电脑端开着，进 **设置 → 局域网同步**，卡片上会直接显示本机地址（如 `http://192.168.1.5:47800`）
2. 手机端进 **设置 → 局域网同步**，把地址填进去 → 点「测试连接」，显示通路 + 两边数据条数
3. 想用电脑那份 → 点 **从电脑拉取**；想把手机上的记录送上去 → 点 **推送到电脑**

规则只有一条：**整包覆盖，不自动合并**。格物卡、论道记录、阅读进度这类数据两边各改一半之后没法判断谁对，所以不做双向合并——覆盖前会自动在本机留一份备份（保留最近三份），点错了还能回去。

- 端口固定 `47800`，被占用时电脑端会顺延到下一个可用端口并显示出来
- 手机填不了 IP 时，先确认两台设备连的是同一个路由器（不是一台连 Wi-Fi 一台连热点）
- Windows 弹"是否允许防火墙"时要允许（专用网络），否则手机连不进来

跨不了局域网时（比如在外地），仍可用 JSON 备份接力：设置 → 数据管理 → 导出全部数据 / 导入备份。

## ★ v2.0 打下的底子（2026-10-24）

### 1. 黑天 / 白天双主题

设置 → 外观 → 主题，两段切换，点击即时生效，**主题选择会被记住**，下次打开还是上次那套。

- **黑天（默认）**：深夜壳 `#0B0E14` 包住全应用，星图在深空里发光；唯独读书的纸卡留一盏暖灯，长时间读不刺眼
- **白天**：雾灰 `#F5F5F7` 底 + 纯白卡片 + hairline 细边，白天在教室/户外看也不反光

星图的节点、连线、标签、图例颜色**跟着主题一起换**，不是简单反色，是两套独立配色。

### 2. 质感：层次靠光影，不靠边框

- 双层柔和投影（近处一层薄描边 + 远处一层大范围弥散），卡片有真正的"浮起来"层次
- 弹层、状态栏、底部 Tab 用 vibrancy 半透明毛玻璃（backdrop blur + saturate）
- 字体走系统回退栈，分段控件做成一体式滑块
- 所有动效统一缓动 `cubic-bezier(.32,.72,0,1)`，不再有生硬的线性过渡

### 3. 全部小图标换成自绘矢量图

一个 emoji 都不剩了。29 个图标全部是内置 SVG sprite（1.8 描边、圆头圆角、跟随文字颜色），在任何系统、任何字号下都清晰，不会被 Windows 的彩色 emoji 字体搞成花脸。

### 4. API 配置重做（含自动拉取模型）

设置 → AI 服务：

1. 选服务商（Ollama / DeepSeek / 硅基流动 / 自定义）
2. 填 Base URL 和 API Key（Key 只存本机，不上传）
3. 点 **拉取** —— 自动请求服务端的模型列表：
   - OpenAI 兼容服务 → 读 `GET {BaseURL}/models`
   - Ollama → 读 `GET {BaseURL}/api/tags`
   - 拉回来填入下拉框，选一个即用；拉不到就手填，不会卡住
4. 点 **测试连接** —— 真发一次请求，显示成功才算接入（侧栏底部绿点=真 AI，黄点=预置脚本）
5. 接入后：伴读讲解、格物追问、论道六哲、哲学书梳理全部走真实模型；任何一环失败自动降级回预置剧本，功能不断

## ★ v2.1 修了什么（2026-10-24）

### 1. AI「配了 API 还是不通」——四个真根因全修了

这一版最重要的事。之前反馈的「填了 Key 却还是在跑预置脚本」，查下来不是一个 bug 而是四个：

| 问题 | 根因 | 现在的行为 |
|---|---|---|
| 关掉再打开就退回预置脚本 | 接入状态只是个内存变量，重启即丢 | 验证结果存本机（配置指纹），重开照样是接上的 |
| 改个字号 / 切个主题就掉线 | `saveSettings()` 无条件把接入标记清零 | 只看服务商 / Base URL / Key / 模型这四项，四项没变就一直有效 |
| 填完 Key 直接去用，还是预置脚本 | 必须手动点「测试连接」才生效 | **填完自动验证**；打开应用也会补验一次，不需要记得点什么 |
| 测试显示已接入，一用就掉回预置 | 上半部配的是「服务商」，实际调用读的是「主力」，两者不联动 | 两处强制同步；测试连接也改成真发一次对话，不再用 `/models` 糊弄 |

顺带修的：在设置里「拉取」选中的模型对主力不生效（之前只有"自定义"才会用你选的模型）；兜底服务没填 Key 时会把真实错误盖成"缺少 API Key"；遇到 401/403 会主动把绿点降级，不再假装已接入。

设置页顶部现在有一条状态带，直接告诉你：**已接入 · DeepSeek / deepseek-chat**、**待验证**、**连接失败（附原因和排查方向）**，或者**未配置**。侧栏底部那盏灯跟着它走。

### 2. logo 和哲学家头像都是自己画的

- **品牌符号**：「日出于书」几何徽章——中心实心圆（太阳核心）+ 六条等距放射线（末端各一个圆点，左右两条再各分叉一条斜线连更小圆点）+ 下方宽弧形书页托座，书页上缘与太阳同心，月牙负空间径向等宽。纯黑单色、扁平 2D，只用正圆/直线/圆弧/圆角，512px 主图与 32px 侧栏印章同源（印章用去末端圆点的压缩标，26px 下仍读作六芒星太阳）
- **六位哲人**：改用**实心剪影**，靠轮廓区分身份 —— 苏格拉底的秃额与络腮胡、爱比克泰德的卷发、康德的三角帽、尼采的八字胡、庄子的发髻、王阳明的方巾。42px 下也认得出来

两者都是内联 SVG（`<symbol>` + `<use>`），没有图标字体、没有第三方图标库、没有现成素材，颜色跟主题和按钮状态自动走。

### 3. 表述去品牌化

之前文档和界面注释里拿某个消费电子品牌当卖点讲，现已全部换成致知自己的说法：层次靠光影、材质靠毛玻璃、动效统一缓动、图标自绘线描。风格是自己长出来的，不是套谁的模板。

## 四、把人机交互从"预置脚本"升级成真 AI（可选）

不配 API 也能用——内置预置脚本保证全功能不断。想接真模型见上一节第 4 条。推荐配置：

- **本地 Ollama**：`http://127.0.0.1:11434/v1`，模型 `qwen2.5:7b`——断网可用，推荐
- **DeepSeek**：`https://api.deepseek.com/v1`，模型 `deepseek-chat`
- **硅基流动**：`https://api.siliconflow.cn/v1`

## 五、朗读换成自然人声（Edge-TTS）

浏览器内置语音偏机械。想要微软神经网络音色（晓晓/云希/陕西话晓妮…）：

1. 电脑安装依赖：`pip install edge-tts fastapi uvicorn`
2. 运行附带的 **edge-tts-bridge.py**：`python edge-tts-bridge.py`
3. 启动后会打印局域网地址（如 `http://192.168.1.5:8787/v1`）
4. 致知 设置 → 阅读与朗读 → 朗读引擎 → Edge-TTS，地址填打印出来的（本机用 `http://127.0.0.1:8787/v1`，手机填局域网 IP）
5. 音色下拉里选一个（推荐晓晓；老乡可以试试陕西话晓妮）

连不上时自动退回系统音，阅读不中断。
