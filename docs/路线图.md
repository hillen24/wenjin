# 致知 · 思想栖所 —— 后续演进路线图

> 写于 v3.9.2（2026-10-30）
> 用途：不是「以后要做什么」的许愿池，是**下一步三个版本的具体动作**。
> 每条都标了「为什么现在做」和「做完能验什么」，否则不做。

---

## 零、先看清我们现在在哪

**已完成的**（v3.9.x）：四模块闭环跑通（星系 / 精读 / 格物 / 论道）、真 LLM 接入层 + 三级降级、文献研读 Agent、公版全文书 14 部、数据备份 + 局域网同步、双端封装（Electron exe + Capacitor apk）、自定义 TTS 引擎。

**当前的真实短板**（不是猜的，是从代码和实拍里看出来的）：

| 短板 | 证据 | 用户感受 |
|---|---|---|
| **数据只在一台设备上** | 局域网同步是「整机快照覆盖」，不是实时协同 | 手机上记的东西，电脑上看不到 |
| **AI 质量不可控** | prompt 是固定模板，没有针对「这段文本」的检索增强 | 讲得对但很泛，用久了像在跟复读机说话 |
| **朗读只解决「能出声」** | 只有合成 + 播放，没有跟读、标记、倍速断点 | 听了就忘，没有闭环 |
| **概念星系是死的** | 27+ 节点是静态图谱，只能点亮不能长出新关系 | 用一年还是那张图 |
| **没有「回看」的入口** | 格物卡、摘录、论道沉淀在「我的哲学书」里，但首页不会提醒你 | 记过的东西等于没记 |

**总纲**：v3.9 是「功能齐了」，v4.0 要做的是**「长出习惯」**——
让用户在碎片时间里被提醒回来，让积累的东西自己长出关系，让每一次使用留下可回看的痕迹。

## 一、v3.10 —— 把「能用」打磨到「顺手」（1~2 周）

> 这一版不加新模块，只修**已经在用、但每次都别扭**的地方。
> 投入小、感知强，是版本节奏的缓冲垫。

### 1.1 手机端首屏冷启动（0.5 天）

现在手机打开是直接进「概念星系」，一张需要用眼睛扫的图。
**改成**：上次读到哪本书 → 顶部一条「继续读 · 《庄子·内篇全》第 42 段」→ 点一下直接落回那一段。

理由：这是「回访型应用」最该做的一件事。打开就能接着上次，比任何新功能都值钱。

### 1.2 朗读的「跟读闭环」（1 天）

现在：点朗读 → 听 → 完事。
**改成**：朗读中，当前段落高亮并跟随滚动；听完自动标记该段已读（可关）；长按段落能「只朗读这一段」。

理由：「精读伴读」最大的浪费是——你听过了，但没标记，下次还是从头找。自动标记把「听」和「进度」缝在一起。

### 1.3 划词三问的「追问链」（1 天）

现在：划一句 → 三问 → 得到一个回答。答完就断了。
**改成**：回答里如果出现了新概念，可以直接「就这个再问一层」，形成追问链；整条链存进「我的哲学书」。

理由：产品原则第一条是「**追问优先于答案**」，但现在的实现其实只给了答案。追问链才是原则的落地。

### 1.4 设置页的「体检报告」（0.5 天）

把散落在各处的状态收成一张表，一键诊断：

```
✓ AI 模型      已接入 · siliconflow / deepseek-ai/DeepSeek-V3
✓ 朗读引擎    硅基流动 TTS · 音色 CosyVoice2:anna
⚠ 数据备份    10 天没备份过
⚠ 星图        有 7 个盲区节点从没点亮
```

理由：配置类功能越多，用户越不知道「现在到底配好了没」。一张体检表省掉所有「是不是我哪里弄错了」的怀疑。

## 二、v4.0 —— 让积累长出关系（4~6 周，核心版本）

> 这一版是项目的**转折点**：从「几个独立工具」变成「一个会生长的系统」。

### 2.1 星图自生长（2 周 · 最高优先级）

**现在**：27 个内置节点，点亮/盲区，静态。

**要做**：星图节点不再是固定的。每个「点亮」的节点 + 每次文献研读导入的文本 + 每张格物卡里的概念，都要能在星图上**生成新的关系边**（继承 / 反驳 / 细化 / 类比）。

具体机制：
- 每次文献研读 Agent 提取概念时，除了「落进方法论库」，还要**给出与已有节点的关系判断**（由 AI 判定，落到四条边之一）；
- 用户可以否决某条边（AI 会误判，这一步必须留）；
- 拒绝的边进入「待定池」，供用户日后翻案。

理由：这是整个项目「哲学系」定位的**技术兑现**。用户导入十份文献后，得到的不是十份笔记，而是一张**属于他自己的思想地图**——每条边都是他和 AI 讨论过的痕迹。这是别家笔记软件给不了的东西。

### 2.2 检索增强的伴读（1.5 周）

**现在**：划一句 → 把这句话 + 几个 prompt 模板发给模型 → 得到回答。
**要做**：先在**用户的全部沉淀**（格物卡 / 摘录 / 论道 / 方法论 / 文献笔记）里做语义检索，把命中的 3~5 条作为上下文一起发出去。

理由：现在的 AI 是**失忆的**——你三个月前问过「我为什么会反复拖延」，今天再问，它不知道你上次怎么答的、自己认定了什么。检索增强把「我的哲学」变成 AI 的记忆。

这是让 AI 回答从「通用正确」变成「针对你」的关键一步。

### 2.3 每日回看（1 周）

**现在**：格物卡沉在「我的哲学书」里。

**要做**：
- 每天首次打开时，如果昨晚有格物卡但没标记行动，回看一次（今天那件事打算怎么办）；
- 每周一次「本周回看」：这一周点亮了什么、写了什么卡、有哪条自己说过的话被自己违反了；
- 晨间已有「回看」入口，把它从手动触发改成**主动推送**（本地通知，不联网）。

理由：产品原则第二条「每次使用必须落到可操作的一步」——现在的「一步」落下去之后就没下文了，用户三周后已经忘了当初为什么立这个志。回看机制是**把一次性的行动变成习惯**的唯一办法。

### 2.4 朗读的深度玩法（1 周）

- **倍速 + 段落级书签**：1.0x~2.0x，快段落 1.8x，慢段落 0.9x（AI 判断哪段需要慢）
- **跟读打卡**：听完一段，标记「听懂了 / 没听懂」，没懂的自动进「明天重听」队列
- **导出音频**：整本书合成 mp3，导出到本地（配合夜跑/通勤）

理由：朗读是这个应用最被低估的能力。DeepSeek 有 API，Edge-TTS 免费音质好，但**没有任何人把它用成「听书 + 复盘 + 复习」的闭环**。

## 三、v4.1 —— 从单机到多端（3~4 周）

### 3.1 增量同步取代整机覆盖（2 周）

**现在**：局域网同步 = 整机快照覆盖，A 覆盖 B 或 B 覆盖 A。

**要做**：基于现有 sync 快照格式做**增量合并**：
- 按记录 id + 更新时间戳合并，而不是整包替换；
- 冲突（如两边同时改了同一张格物卡）保留两个版本，让用户选，不自动裁决；
- 同步改成**后台自动**（应用启动时 + 每 5 分钟），不用手动点。

理由：「数据在家」是产品原则第三条，但「数据只在一部手机里」违背了原则的精神。合并逻辑比覆盖逻辑难，但这是「一个记录在所有设备都在」的必要条件。

### 3.2 导入导出全家桶（1 周）

- 完整数据导出（一个 zip：设置 + 全部数据 + 备份历史）
- 导入时**预览差异**（新增 N 条 / 修改 M 条 / 冲突 K 条），逐项确认
- 分享单张格物卡 / 单段摘录为图片（长图，带应用署名）

理由：用户信任一个应用的前提是「我的东西随时能拿走」。加上这一条，「数据在家」才不只是技术选择，而是承诺。

### 3.3 手机端专项（1 周）

- **后台朗读**：Android 前台服务（复用 @capacitor-community 的 audio 能力），锁屏继续念
- **通知**：格物提醒 + 每日回看 + 文献研读完成
- **小组件**：桌面放一个「今天的格物题」快捷入口

理由：手机端目前最大的短板是**「只能前台用」**。而这个应用的典型使用场景（睡前听书、走路想问题）天然发生在后台。

## 四、v5.0 —— 可能的公网化（暂不排期，有钱再说）

只有满足下面**全部**条件才启动：

1. v4.0 的「星图自生长」和「检索增强」已被真实使用证明有效（用户留存 > 30 天）
2. 有明确的**付费意愿**证据（不是「觉得不错」，是「愿意每月付 10 块」）
3. 服务器成本模型算得清（推理成本 vs 订阅收入）

**做什么**：账号体系、云端模型代理（用户自己的 Key 存在服务端？不，**永远存本地**）、跨设备实时同步、社区（**只做「思想对谈」，不做朋友圈**）。

**明确不做**：不卖数据、不做算法推荐、不做社交关系链。这个应用的立场是「安静的」，一旦变成社交产品就死了。

## 五、技术债（穿插做，不单独排版本）

| 项 | 现状 | 什么时候做 |
|---|---|---|
| **单测只覆盖 core** | app 包的 Vue 视图几乎没测 | 每次改视图逻辑前先补 |
| **Playwright 视觉回归没进 CI** | 现在靠我手动跑 | 有 CI 后接上，截图对比 |
| **构建产物 435KB（gzip 175KB）** | 单包全量加载 | v4.1 做路由级代码分割 |
| **星图力导向自己写的** | 节点少时够用，200 节点会卡 | 星图扩到 100 节点前重写 |
| **electron-builder 每次版本变更后首次 dist 必失败** | safe-delete 拦 dist-app 清理 | 换成自己的清理逻辑（挪走而不是删） |

## 六、优先级排序（如果只能做三件事）

1. **星图自生长**（2.1）—— 这是「思想栖所」这个名字的兑现，是别家抄不走的
2. **检索增强的伴读**（2.2）—— 让 AI 从「聪明」变成「懂你」，成本最低、感知最强
3. **每日回看**（2.3）—— 把「用过」变成「一直在用」，留存的分水岭

---

## 七、一句话总结

> v3.9 解决了「能不能用」，v3.10 打磨「用得顺不顺」，
> v4.0 让它「记住你、跟你一起长」，
> v4.1 让它「到哪都在」。
> 公网化是最后的事，且很可能永远不做——**这个应用的价值在于它是安静的、属于你自己的**。
